# Original TLI and anniversary versions

The existing GitHub branches, release tags and release assets are preserved.
The anniversary work has its own codex/anniversary-preview-1 branch and
anniversary-preview-1 prerelease tag. It does not replace main, master, the
previous latest release, or its downloads.

## Version identity

This preview is identified by its own Git tag. In-app/native version strings
remain those of the verified candidate; publishing does not change the runtime
just to alter a label. Android remains Companion Beta 0.1.0 (8).
A future production release can advance those labels with its own validation.
