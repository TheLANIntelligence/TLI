# TLI anniversary building roadmap

TLI remains a private home console that understands computers, devices, files
and local services, notices meaningful changes, and helps users take controlled,
dependable actions. Preserve that value and existing working installations.
This is a building roadmap, not a commitment to package a release or replace TLI.
