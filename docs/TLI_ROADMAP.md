# TLI Roadmap

Living document.

## Anniversary implementation checkpoints — September 2026

The anniversary work preserves the existing local home console and takes priority over the older broad phases below.

Current priority: close gaps in everyday reliability, Narrator usefulness and storage review before adding integrations. MCP is deferred again by user direction. Next release gate is verification of the existing workflows on the actual supported installations and devices.

- **Implemented:** dependable Narrator/action results and conservative device targeting. See `ANNIVERSARY_RELEASE.md`.
- **Implemented:** shared device context, guided diagnostics/history, memory controls, model visibility and explicit image troubleshooting. See `ANNIVERSARY_INTELLIGENCE.md`.
- **Implemented:** clearer storage review, truthful scan coverage, measured Narrator check-ins and backend/interface mismatch fixes. See `STORAGE_NARRATOR_REFINEMENT.md`.
- **Implemented:** source distribution validation, non-destructive startup checks, fresh Windows Python environment checks and synthetic source-code rollback/backup rehearsal. See `ANNIVERSARY_DISTRIBUTION.md` and `ANNIVERSARY_INSTALL_ROLLBACK.md`.
- **Before distribution:** validate native installers, dependency installation, physical device/phone/mesh workflows and full installation rollback. These remain unverified; the source-package check does not replace them.

No new model tiers, automatic model routing, vector memory, Skills, MCP, Home Assistant, voice, room nodes or autonomous workflows are part of the current release scope.
