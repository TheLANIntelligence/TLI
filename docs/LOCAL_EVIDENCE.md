# Local checkpoint evidence

Historical documents refer to local build directories containing test logs,
screenshots, isolated fixtures and earlier candidates. These records remain
preserved locally; they are not uploaded wholesale into this public branch.

Links marked **local evidence** lead here deliberately. The underlying raw file
is not represented as publicly available. Current release identities, test counts,
limitations and artifact hashes are in the
[public verification record](../release/verification.json).

Application model-evaluation reports retain their original provenance, including
local development paths, to preserve existing hash contracts. Synthetic examples
are not measurements of a reader's computer. No household stores, credentials,
pairing bundles, models, development environments or rejected experimental source
are included in this publication.
