A FRESH START

These 1.4.0-beta packages include the current desktop workspace shown on the homepage. Extract into a new folder and stop your old TLI before launching. Keep the old folder and saved data intact; this release does not automatically migrate or replace them. Website examples use illustrative data, and the phone Companion remains a separate beta.

01 / WINDOWS

From ZIP
to workspace.

Set aside a few minutes for the first launch. An internet connection is needed to install dependencies.

  1. 01

    Download the public beta

    Save TLI_1.4.0-beta_Windows.zip to your PC. The download is available immediately; an email address is optional.

  2. 02

    Extract All

    Right-click the ZIP and choose Extract All. Use a new, writable folder such as Documents\TLI-1.4.0-beta. Keep old TLI folders intact and stop the old host through its own launcher or Terminal before starting this copy.

  3. 03

    Open TLI.exe

    Double-click TLI.exe in the fully extracted folder and complete first-time setup. The launcher is unsigned, so Windows may show a publisher warning. Check the release source and checksum before deciding to open it.

  4. 04

    Complete setup in your browser

    Open localhost:8000 (opens in a new tab) if the browser does not open automatically. The inference runtime is included. Select and download a model that fits your computer, or configure a compatible local provider, before asking for AI-generated responses. Closing the browser leaves the Windows host running; use Local Setup to stop it.

BEFORE YOU START

A little preparation.

  • 64-bit Windows 10/11 and 64-bit Python 3.10–3.14 (3.14 recommended).
  • Microsoft Visual C++ v14 x64 Redistributable for the bundled inference runtime.
  • A writable installation folder.
  • Internet for the first setup and model downloads.
  • Available storage and memory for your chosen model.

The launcher can install Python 3.14 through Windows Package Manager if needed. If setup cannot finish, install 64-bit Python 3.14 for Windows, then reopen TLI. If the runtime check reports missing dependencies, install the Microsoft redistributable above and reopen TLI. Use TLI_Diagnostics.bat to see setup errors.

Verify the Windows download +

This SHA-256 checksum identifies the published ZIP.

b55d2bc8e1362d46ea5be4069b5ff7e0355081b211dc64e2ffb5ece83b666e75

In PowerShell, run this from the folder containing the ZIP:

Get-FileHash .\TLI_1.4.0-beta_Windows.zip -Algorithm SHA256

Compare the entire returned hash with the value above.

02 / MACOS

Unzip. Launch.
Make it yours.

One ZIP for Apple Silicon and Intel. This is a Python-based installation with a Terminal launcher; it is not a notarized Mac app or a DMG.

01 / BEFORE YOU START

Check your Mac.

The bundled runtime requires macOS 14+ on Apple Silicon or macOS 13.3+ on Intel. Install Python 3.10 or newer. First setup needs internet access to install dependencies.

02 / A NEW FOLDER

Download and extract.

Save TLI_1.4.0-beta_macOS.zip and extract it into a new, writable folder such as ~/Applications/TLI-1.4.0-beta. Keep old folders and saved data intact. Stop your old TLI before launching the new copy.

03 / YOUR WORKSPACE

Open TLI_Start.command.

Open TLI_Start.command in the extracted folder, or run bash TLI_Start.command from Terminal there. Follow setup and keep Terminal open while using TLI. Press Control+C to stop it. Model weights are a separate download.

Verify the macOS download +

This SHA-256 checksum identifies the published Mac ZIP.

3fc0f206e7fa04da2099e4460c4de74cc8252b0aacfc9d7b6d7fc8b8f333a636

In Terminal, run this from the folder containing the ZIP:

shasum -a 256 TLI_1.4.0-beta_macOS.zip

Compare the entire returned hash with the value above.

Get in touch ↗
Which features am I downloading?+

Both desktop downloads are TLI 1.4.0-beta, released October 11, 2026. They include Ask TLI, the refreshed workspace and themes, Files, Vault, reviewed LAN connections, small-app Builder, and the bundled inference runtime. The website tour uses illustrative data and example responses.

See the 1.4.0-beta release notes for changes in that release. The separate Android Companion beta needs its own app and a compatible, configured host. Neither desktop ZIP includes a phone app, and this page does not offer a phone download.

Do I need an AI model?+

Yes, AI-generated answers require a configured model. The llama.cpp runtime is included, but model weights download separately. You can also configure a supported local provider such as LM Studio. Choose a model appropriate for your computer; download size, memory needs, and response speed vary by model and hardware.

Does everything run offline?+

Local conversation can work offline once a compatible local model, runtime, and dependencies are installed. Downloads and optional internet services need a connection. The provider and integrations you select determine where a request is sent; choosing a cloud service means that service receives the relevant request.

Windows setup stopped or Python was not found.+

Make sure the ZIP is fully extracted into a writable folder and your internet connection is working. If automatic Python installation fails, install 64-bit Python 3.14, then open TLI.exe again.

Run TLI_Diagnostics.bat from the extracted folder for visible setup output. If setup still fails, email the error text to thelanintelligence@gmail.com.

My browser opens the wrong page, or will not connect.+

Wait for setup to finish; on Mac, keep the Terminal window open. Use the address shown by the launcher, normally http://localhost:8000 on the same computer. Another server or older TLI may already use port 8000. Stop the old TLI through its own controls, or close the other server you recognize, before starting this installation.

If the page still will not load, check the launcher output for errors and include them when requesting help.

Where can I find release notes and earlier versions?+

Use the GitHub releases page for published release notes and package assets. Choose TLI_1.4.0-beta_Windows.zip or TLI_1.4.0-beta_macOS.zip for your platform. GitHub's “Source code” archives are a different download and are not the package described here.
