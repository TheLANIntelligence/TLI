A FRESH START

These 1.4.0-beta packages include the desktop tools shown on the homepage. Extract into a new folder and stop your old TLI before launching. Keep the old folder and saved data intact; this release does not automatically migrate or replace them. TLI is beta software. 01 / WINDOWS

From ZIP
to workspace.

Set aside a few minutes for the first launch. An internet connection is needed to install dependencies.

  1. 01

    Verify and download

    Verify your email for Windows, then save TLI_1.4.0-beta_Windows_Onboarding.zip to your PC.

  2. 02

    Extract All

    Right-click the ZIP and choose Extract All. Use a new, writable folder such as Documents\TLI-1.4.0-beta. Keep old TLI folders intact and stop the old host through its own launcher or Terminal before starting this copy.

  3. 03

    Open TLI.exe

    Double-click TLI.exe in the fully extracted folder, then choose Set up TLI. Follow progress in the launcher while it prepares dependencies and shortcuts. Windows may ask you to approve Microsoft’s signed runtime installer. The launcher is unsigned, so Windows may show a publisher warning. Check the release source and checksum before deciding to open it.

  4. 04

    Make TLI yours

    Your browser opens automatically when the workspace is ready. The guided welcome helps you choose a theme, set an optional PIN, and configure AI. The included soundtrack has play/pause and volume controls; if your browser blocks autoplay, choose Let’s begin or Play music. You can explore first and download a model later. AI-generated answers need a configured model. Closing the browser leaves the Windows host running; use Local Setup to stop it.

BEFORE YOU START

A little preparation.

  • 64-bit Windows 10/11.
  • Setup prepares supported Python and missing Microsoft runtime dependencies.
  • A writable installation folder.
  • Internet for the first setup and model downloads.
  • Available storage and memory for your chosen model.

Existing 64-bit Python 3.10–3.14 installations are supported. If needed, setup installs Python 3.14 through Windows Package Manager and requests Microsoft’s signed x64 runtime installer. An optional local AI issue does not block the welcome page; the launcher keeps repair details available. If setup needs help, use Open logs in the launcher or TLI_Diagnostics.bat.

Get in touch ↗
Which features am I downloading?+

Both desktop downloads are TLI 1.4.0-beta, released October 11, 2026. Ask TLI supports writing, learning, planning and coding conversations. Add selected documents or saved notes when useful. Connected tools include LAN Messages and approved file sharing, computer-help reports and saved steps, supported Shelly controls, reviewed manual routines, Files, the Free Space map, a passphrase-protected encrypted Vault, and Builder for small HTML/CSS/JavaScript apps.

The bundled inference runtime is included; model weights download separately. Free Space lets you review exact files before moving them to Trash. Moving a file to Trash may leave its bytes on the same drive. Website examples use illustrative data and example responses.

See the 1.4.0-beta release notes. The separate Android Companion beta needs its own app and a compatible, configured host. Neither desktop ZIP includes a phone app, and this page does not offer a phone download.

Can I chat and share files around my home?+

Use LAN Messages to send text between trusted TLI computers on your local network. Both computers need TLI running, a reviewed secure connection and permission to exchange messages. A delivery acknowledgement means the other computer recorded the message, not that a person read it.

For file sharing, the recipient reviews and accepts each incoming file before its contents transfer. Verified files arrive in the encrypted TLI Inbox for deliberate download. This is individual file sharing, not automatic folder synchronization.

How does computer help work?+

Describe a problem, review an available check for the chosen computer, and save its report with the steps you tried. Ask TLI about the selected evidence, record what happened, and reopen the investigation if the problem returns.

Reports show what was observed and when. A completed check does not prove a cause or a repair. Remote checks need separate permission, and the lightweight inference Node supplies AI compute only.

Which Shelly devices can I use?+

TLI supports local on/off control and reported state for compatible Shelly Gen2/Plus switch and relay devices. Power readings are available when the device reports them. Add the device on your local network, name it, then use its controls or a direct request such as “Turn on Office Lamp.” TLI checks reported state after a command and tells you when the result cannot be confirmed.

Support depends on the model and its local interface. Shelly Gen1 and devices requiring Shelly device authentication are not supported by this integration. Check your model's compatibility before connecting it. Routines are reviewed sequences you run manually; automatic schedules are not enabled in this release.

What can TLI read from documents and images?+

Choose supported text files or review extracted text from a PDF or DOCX before sending your question. TLI shows extraction coverage and may send selected excerpts to fit your model. PDF/DOCX extraction does not include OCR or preserve the original page layout. Image-only or protected documents may not yield usable text.

Questions about shared images and screenshots require a compatible vision model. A screenshot is the snapshot you attach; TLI does not continuously watch your screen. Review AI answers and cited passages against the original source.

What does Builder create?+

Describe a small browser app, generate HTML/CSS/JavaScript, try the isolated preview, ask for improvements, and download a saved version as a ZIP. Earlier revisions remain available. Generated apps use in-memory state that resets on reload; Builder projects and revisions are saved on your TLI host.

Builder does not install packages or run generated servers. Try the behavior yourself and review the source. Its browser smoke checks are advisory, and generated code can need several revisions.

Do I need an AI model?+

Yes, AI-generated answers require a configured model. The llama.cpp runtime is included, but model weights download separately. You can also configure a supported local provider such as LM Studio. Choose a model appropriate for your computer; download size, memory needs, and response speed vary by model and hardware.

Does everything run offline?+

Local conversation can work offline once a compatible local model, runtime, and dependencies are installed. Supported local Shelly controls need the host and device on a working local network. Downloads, internet search and cloud integrations need connectivity. The provider and integrations you select determine where a request is sent; choosing a cloud service means that service receives the relevant request.

You can explicitly select a trusted LAN computer for supported text inference after configuring trust and permission. The primary TLI host remains necessary, and an unavailable model does not automatically switch the request to another computer.

Windows setup stopped or Python was not found.+

Make sure the ZIP is fully extracted into a writable folder and your internet connection is working. If automatic Python installation fails, install 64-bit Python 3.14, then open TLI.exe again.

Run TLI_Diagnostics.bat from the extracted folder for visible setup output. If setup still fails, email the error text to thelanintelligence@gmail.com.

My browser opens the wrong page, or will not connect.+

Wait for setup to finish; on Mac, keep the Terminal window open. Use the address shown by the launcher, normally http://localhost:8000 on the same computer. Another server or older TLI may already use port 8000. Stop the old TLI through its own controls, or close the other server you recognize, before starting this installation.

If the page still will not load, check the launcher output for errors and include them when requesting help.

Where can I find release notes and earlier versions?+

Use the GitHub releases page for published release notes and package assets. Choose TLI_1.4.0-beta_Windows_Onboarding.zip or TLI_1.4.0-beta_macOS.zip for your platform. GitHub's “Source code” archives are a different download and are not the package described here.
