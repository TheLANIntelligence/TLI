TheLegatoIntelligence

TLI is a local, offline-first LAN console — an AI-powered home OS dashboard that runs entirely on your hardware. No cloud, no subscriptions, no data leaving your network.

What is TLI?

TLI gives you a unified control panel for your local environment: AI chat, encrypted storage, smart home control, file management, network topology, and system diagnostics — all from a single browser tab.

💬
Local AI Assistant
Chat with local LLMs via LM Studio or the bundled Qwen2.5 model (Lite, Standard, or Power).
🔐
Encrypted Vault
AES-256-GCM encrypted files, secrets, and notes. Only unlocked with your master password.
🏠
Home Automation
Control Shelly smart devices, build automations, and ask AI to control your home.
🌐
Mesh Network
Connect multiple TLI nodes on your LAN, share AI capacity, and monitor peers.
📁
File Manager
Scan, organize, and visualize disk usage. Treemap for storage, rule-based sorting.
🎮
Game Optimizer
Auto-detect running games and get AI-generated performance presets.

First-Run Setup

On first launch, TLI walks you through a 4-step wizard:

  1. Node Name — Give this TLI instance a name (e.g. "Gaming PC", "Home Server"). Used to identify this node on your mesh.
  2. Access PIN — Optionally set a 4–32 character PIN to lock TLI. Recommended if other people share your LAN. Can be skipped and set later.
  3. LM Studio — Enter the URL of your LM Studio server (default: http://localhost:1234). TLI tests the connection and lists available models. Can be skipped if using the bundled AI.
  4. Done — The wizard marks onboarding complete and launches the main interface.

Re-run wizard: Settings → scroll to bottom → "Reset onboarding".

Navigation

The left sidebar contains icon buttons for each panel. Click any icon to switch panels. The active panel is highlighted. Panel names appear as tooltips on hover.

The header shows the node name, AI status pill, and quick-access buttons (lock, manage AI source).

Main — AI Chat

The core panel. Type a message and press Send or Enter to chat with the local AI.

Chat Controls

  • Brain selector — Choose which model handles your request. "Auto" picks the best model based on your message content (code → Qwen, reasoning → DeepSeek, general → default).
  • Teaching Mode — Toggle in the chat toolbar. When on, the AI explains step-by-step. When off, it gives concise answers.
  • History button — Opens the conversation drawer (right side). Lists past conversations. Click a conversation to resume it. Delete with the trash icon.
  • Script Request — Checkbox in Advanced Controls. Tells the AI the output should be valid script code.
  • Temperature / Max Tokens — Advanced sliders. Temperature controls creativity (0 = deterministic, 1 = creative). Max tokens limits response length.

Vault Secrets Injection

If the vault is unlocked, you can inject specific secrets into the chat context. The AI will only reveal them when explicitly asked. Enable via Include Vault Secrets in Advanced Controls.

Conversation Persistence

Every chat exchange is automatically saved. Conversations are titled from your first message. Access previous conversations via the History button. Conversations are scoped to your session user — other users cannot see yours.

AI Status Badge

Below the input, the badge shows which AI source is active: Bundled AI — local Qwen2.5 model   LM Studio — your LM Studio server   Offline — no AI available.

If you see "No available AI provider": start LM Studio and load a model, or wait for the bundled AI to initialize (first run may take a minute).

Dashboard

System overview with live status cards, quick-action buttons, and recent activity.

  • Status cards — AI status, mesh node count, vault status, device count. Click cards to jump to the relevant panel.
  • Quick Actions — Buttons for common tasks: "New Chat", "Open Vault", "Scan Files", "Check Devices".
  • Recent Activity — Local activity log stored in localStorage. Records panel opens, AI interactions, vault operations. Cleared on "Clear History" in Settings.

Vault

An encrypted storage system protected with AES-256-GCM. Your master password never leaves your device.

Initial Setup

  1. Click Set up Vault and enter a strong master password.
  2. The vault is initialized with a unique key derived from your password (PBKDF2-SHA256, 260,000 iterations).
  3. Enter your password to unlock. The vault stays unlocked for 30 minutes of inactivity.

Files

Upload any file (drag-and-drop or the Upload button). Files are encrypted at rest. Download decrypts on the fly to your browser. Delete is permanent.

Secrets

Key-value pairs for passwords, API keys, and credentials. Add via + Add Secret. Each secret has a name (key) and value. Secrets can be injected into AI chat context.

Notes

Encrypted markdown notes. Create, edit, and delete notes from the Notes tab. Useful for sensitive documentation.

Backup & Reset

  • Export Backup — Downloads an encrypted archive of all vault contents. Keep this safe.
  • Reset Vault — Permanently destroys all vault data. Requires current password + typing "RESET VAULT". Irreversible.

If you forget your vault master password, the data cannot be recovered. The password is never stored — only a PBKDF2 hash is kept.

Home Automation

Control Shelly smart devices on your LAN and build automation rules.

Device Setup

  1. Go to Settings → Shelly Devices and add a device by IP address.
  2. Assign a friendly name (e.g. "Living Room Lamp").
  3. The device appears in the Home Automation panel.

Manual Control

Each device card shows current state (on/off, power consumption). Use the toggle to switch relays. The AI can control devices via chat: "Turn off the living room lamp."

Automations

Create scheduled or condition-based automations in the Automations sub-panel. Define triggers (time, device state) and actions (relay on/off, group scenes).

Scenes

Group multiple device actions into a named scene (e.g. "Movie Mode" = dim lights, activate specific relays). Trigger scenes from the panel or via AI chat.

File Storage

Scan directories, organize files by rules, and visualize disk usage.

Scanner

  1. Enter a directory path (or select a preset) and click Scan.
  2. The scanner reads file names and extensions (not content). Results show size, type, and modification date.
  3. Use the extension table to see what types of files are present.

Organizer

Set rules (e.g. "move all .mp4 files to /Videos") and click Organize. The organizer moves files in batches. An Undo option is available immediately after each operation.

Visualizer (Treemap)

Switch to the Visualizer panel for an interactive treemap of disk usage. Each rectangle represents a file or folder — size is proportional to disk usage. Click to drill down, hover for details.

Game Optimizer

Auto-detect running games and generate hardware-aware performance presets.

How It Works

  1. Open the Game Optimizer panel — it immediately starts polling for a running game (foreground process scan every 2.5 seconds).
  2. When a game is detected, the title, PID, store (Steam / Epic / process scan), and live CPU/GPU/RAM metrics appear.
  3. Select a preset: Max FPS, Balanced, or Quality.
  4. The AI generates recommendations based on your detected hardware and the running game.

Manual Mode

If your game isn't auto-detected, click Add Game Manually and paste the full .exe path. The path is added to an allowlist for future scans.

Devices

Inventory of connected USB drives, printers, and LAN devices.

USB Storage

Lists connected USB drives with capacity, free space, and mount point. Click a drive to open its directory in the File Storage scanner.

Printers

Discovers network printers via SNMP and WMI. Shows printer name, IP, and status. Test print sends a test page.

LAN Scan

Scans the local subnet for active devices. Shows IP, hostname, MAC address (where available), and detected services. Results are cached until the next manual rescan.

Mesh Network

Connect multiple TLI instances on your LAN to share AI capacity, monitor remote nodes, and send tasks.

Roles

  • Standalone — Default. Not connected to any mesh.
  • Host — Primary node. Accepts members, proxies AI requests, and maintains the mesh directory.
  • Member — Routes all AI chat requests to the host. Shares its status with the host.

Joining a Mesh

  1. On the host node: click Become Host.
  2. On the member node: enter the host's IP:port and click Join Mesh.
  3. The member appears in the host's Mesh Directory once the heartbeat is received.

Remote Actions

From the Mesh Directory, you can: Ping a node, fetch its Diagnostics (CPU/RAM/disk), view Recent Logs, and trigger Maintenance (clear temp files, refresh).

Presence

Node presence is based on heartbeat age: Online <20s   Idle <2m   Offline >10m.

TLI Chat

Real-time mesh chat between TLI nodes on your LAN. Messages are not AI-generated — they go directly to connected nodes.

  • Select a target node from the dropdown.
  • Type a message and press Send.
  • Messages appear in the thread with sender, timestamp, and node name.
  • Requires at least two TLI nodes active on the same LAN.

Tools & Scripts

AI-generated scripts and one-click tool execution.

Script Generator

  1. Describe what you need in plain language (e.g. "PowerShell script to find duplicate files in C:\Users").
  2. Select the target shell: PowerShell, Bash, Python, CMD.
  3. Click Generate — the AI writes the script and it appears in the editor.
  4. Save stores the script to your tools library. Copy puts it on the clipboard.

Saved Tools

Previously generated scripts are listed in the My Tools tab. Run them directly (executes on the server), copy, or delete.

Run executes on the TLI server process. Review scripts before running. There is no sandboxing.

Settings

Node Identity

Set the node name and device nickname used throughout the UI and mesh directory. The node ID is auto-generated and cannot be changed.

Access PIN

Set a 4–32 character PIN to lock TLI. When a PIN is set, the lock screen appears on load and after the browser tab is closed. Sessions last 24 hours. Remove the PIN to return to open access.

  • Changing the PIN requires the current PIN.
  • Removing the PIN also revokes all active sessions.
  • If locked out, use the Forgot PIN? link on the lock screen.

Intelligence (AI Source)

Choose how TLI routes AI requests:

  • Auto — Uses local AI if available, falls back to LAN host if not.
  • Local Only — Only uses LM Studio or bundled AI on this machine.
  • LAN Only — Routes all requests to a mesh host node.
  • Prefer Local / Allow LAN — Uses local first; LAN if local is unavailable.
  • Prefer LAN / Allow Local — Uses LAN host first; local as fallback.

LM Studio URL

The URL of your LM Studio OpenAI-compatible server. Default: http://localhost:1234. Test the connection and save via the Update LM Studio URL section in Settings.

UI Mode

Switch between Classic (single column, compact) and Dash2 (modern dashboard layout with cards). Both modes show the same panels.

AI Providers

TLI supports two local AI providers, tried in order:

1. Bundled AI (Qwen2.5)

A local AI model that runs entirely on your machine. Choose from Lite (~1 GB), Standard (~2 GB), or Power (~4.5 GB) depending on your RAM. Handles general questions, chat, and coding. No external dependencies.

Status: visible on the AI badge and at Settings → AI Model.

2. LM Studio

Connect any model loaded in LM Studio. Recommended for code generation and complex reasoning. Supports auto-routing: TLI selects the best model based on message content.

Security & PIN

TLI is designed for trusted LAN environments. Key security properties:

  • All data stays on your machine/LAN. No telemetry, no cloud sync.
  • Vault encryption: AES-256-GCM with PBKDF2-SHA256 key derivation (260k iterations, 32-byte salt).
  • Sessions are tied to cookies (httponly, samesite=strict). Valid for 24 hours.
  • The PIN hash is stored, never the PIN itself.
  • All conversation and memory data is scoped per user — users cannot access each other's history.
  • HTTPS is supported via a self-signed TLS certificate (auto-generated on first run if TLI_NO_TLS is not set).

Troubleshooting

Lock screen won't dismiss

Check if a PIN is set: GET /system/pin/status in your browser. If enabled: false, hard-refresh (Ctrl+Shift+R). If enabled: true and you don't know the PIN, use Forgot PIN? on the lock screen.

AI chat returns "No available AI provider"

  • Start LM Studio and load a model.
  • Verify the LM Studio URL in Settings matches your server address.
  • Check bundled AI status at Settings → AI Model. If the model file is missing, click Download.

Command palette opens on load

Hard-refresh the browser (Ctrl+Shift+R) to clear the cached JavaScript files.

Vault says "Vault locked" after unlock

Vault sessions expire after 30 minutes of inactivity. Re-enter your master password to unlock again. This is by design.

Mesh node not appearing in directory

  • Ensure both nodes are on the same LAN subnet.
  • Verify the host node's address is correct on the member side.
  • Check that port 8000 (or your configured port) is not blocked by a firewall.

Games panel shows "No game detected"

The game scanner reads the foreground window process. Ensure the game is running and in the foreground. For launchers that use indirect processes, use Add Game Manually with the full .exe path.
