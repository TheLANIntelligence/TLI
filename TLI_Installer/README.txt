LEGACY ELECTRON INSTALLER TOOLING
=============================================
This directory preserves the earlier installer sources. Generated bundles and
node_modules are excluded from Git. The historical instructions below apply
only to a prepared legacy package, not to a current source checkout.

For current setup, use ../README.md and the TLI_Start / TLI_Setup launchers.
Current release downloads: https://github.com/TheLANIntelligence/TLI/releases

=============================================
  TheLANIntelligence (TLI)  v0.9.9.1
  Your local AI-powered home console.
=============================================

QUICK START (no install needed)
--------------------------------
1. Double-click  tli_backend.exe
2. A console window opens — leave it running.
3. Open your browser and go to  http://localhost:8000
4. That's it.


OPTIONAL: FULL INSTALL (auto-start on login + Desktop shortcut)
---------------------------------------------------------------
1. Right-click  install.bat  and choose "Run as administrator"
2. TLI will copy itself to your AppData folder and set up auto-start.
3. A shortcut is placed on your Desktop for next time.

After installing, you no longer need to keep the extracted folder —
TLI will start automatically every time you log in.


DOWNLOAD AI MODEL
-----------------
TLI ships without an AI model to keep the installer small.
After opening TLI for the first time, click the  "AI: Bundled"  button
in the top-right corner to download a model (~1-4 GB depending on tier).


UNINSTALL
---------
Run  uninstall.bat  to remove TLI from this machine.
(Only needed if you ran install.bat first.)


NEED HELP?
----------
Open TLI and ask the AI anything, or go to the Manual panel in the sidebar.
