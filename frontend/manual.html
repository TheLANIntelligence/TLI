TheLANIntelligence

TLI is a local, offline-first LAN console — an AI-powered home OS dashboard that runs entirely on your hardware. No cloud. No data leaves your network. Core features run free — Pro unlocks advanced capabilities. Everything works on your LAN whether or not you have internet access.

Quick Start Guide

New install to first AI response in under 5 minutes.

  • Run install.bat Extract the TLI zip, double-click install.bat. It copies files, sets up auto-start, and creates a Desktop shortcut.
  • Open TLI in your browser Use the Desktop shortcut or go to http://localhost:8000. TLI opens in your default browser — no app required.
  • Complete the setup wizard Name your node (e.g. "Home Server"), set an optional access PIN, and continue. Takes about 60 seconds.
  • Download an AI model When prompted, click Download Qwen2.5. The Lite preset (~1 GB) is recommended for most machines. Download runs in the background.
  • Start chatting Once the model downloads, the AI badge turns green. Type a message and press Enter. You're running a fully local AI assistant.
  • Access from other devices On any device on your home network, open a browser and go to http://your-pc-ip:8000. No install needed on those devices.

Find your PC's IP: Open a terminal and run ipconfig. Look for the IPv4 address under your active adapter (usually 192.168.x.x). Alternatively, TLI's Mesh panel shows your node address automatically.

Installation

TLI is distributed as a ZIP package. There is no traditional installer wizard — just a batch file that sets everything up.

Requirements

  • Windows 10 or 11 (64-bit)
  • ~200 MB disk space for TLI itself
  • ~1–5 GB additional disk space for the AI model (downloaded separately after install)
  • Any modern browser (Chrome, Edge, Firefox) — no special browser required

Install Steps

  1. Download TLI_dist_0.9.9.8.zip and extract it anywhere (e.g. your Desktop or Downloads folder).
  2. Open the extracted folder and double-click install.bat. No admin rights required.
  3. The installer copies TLI to %AppData%\Local\TheLANIntelligence\, registers it to auto-start on login, and creates a Desktop shortcut.
  4. Your browser opens automatically to http://localhost:8000. Complete the setup wizard.

Auto-start: After install, TLI's backend starts automatically every time you log into Windows. You don't need to do anything — just open your browser and go to localhost:8000.

Uninstalling

Run uninstall.bat from the install directory (%AppData%\Local\TheLANIntelligence\). This removes the backend, startup task, and Desktop shortcut. Your vault data and settings in the data\ subfolder are preserved — delete that folder manually if you want a complete wipe.

Accessing TLI from Other Devices

TLI runs on your machine and is accessible to any device on your home network. No install is needed on those devices.

  1. Find your PC's IP address: open a terminal and run ipconfig. The IPv4 address looks like 192.168.1.x.
  2. On any other device (phone, laptop, tablet), open a browser and go to http://192.168.1.x:8000.
  3. TLI loads in that browser. It's your TLI instance — same vault, same AI, same everything.

If the other device can't connect, check that your Windows Firewall allows port 8000. TLI attempts to add this rule automatically at startup, but you may need to approve it.

First-Run Setup

On first launch, TLI walks you through a short setup wizard:

  1. Node Name — Give this TLI instance a name (e.g. "Gaming PC", "Home Server", "Office"). This name appears in the mesh directory when other TLI nodes discover yours.
  2. Access PIN — Set a 4–32 character PIN to lock TLI. Recommended if others share your network. You can skip this and set it later in Settings.
  3. AI Setup — TLI checks whether a local AI model is installed. If none is found, you'll see a prompt to download Qwen2.5. Pick a preset (see below) and click Download — it runs in the background. If storage or hardware is a concern, you can skip this step and use a mesh node's AI instead — see AI Providers.
  4. Done — The wizard marks setup complete. TLI lands on the Dashboard.

Dashboard

The Dashboard is TLI's home screen. It loads automatically on startup and gives you a live overview of your entire system at a glance.

Status Cards

Four cards show the current state of the most important systems:

  • AI Status — Whether the local AI is running and which model is loaded.
  • Mesh — How many TLI nodes are active on your LAN.
  • Vault — Whether your vault is locked or unlocked.
  • Devices — Count of detected smart home and USB devices.

Click any card to jump directly to that panel.

System Vitals

Live CPU, RAM, and disk usage. Refreshes automatically. Disk shows your system (C:) drive by default.

Narrator

The Dashboard narrator cycles through contextual status messages every 9 seconds — covering AI state, devices, mesh health, vault status, storage, and tips. It never repeats the same message twice in a session.

Suggested Actions

Context-aware action buttons that update based on your current system state. For example, if no AI is loaded, an action to download the model appears. If smart devices are registered, quick scene triggers are shown.

Live System Feed

A real-time event stream that shows what TLI is doing across all its systems. Events appear as cards with a timestamp, category color, and a short description. Categories include:

  • AI — model started, routing decisions (e.g. "Routing to mesh — CPU at 92%")
  • Game — game detected or closed
  • Mesh — peer joined or left your mesh
  • System — general node events

The bell icon in the header shows an unread badge when new events arrive while you're on another panel. Click the bell to jump to the Dashboard and clear the count. The badge resets automatically when you return to the Dashboard.

AI Chat

The core panel. Type any question, task, or command and press Send or Enter.

TLI's AI knows the current date and time, your node name, your smart home devices, and your LAN state. You don't need to tell it context — it already has it.

What the AI Can Do

  • Answer general questions and have natural conversations
  • Control smart home devices: "Turn off the living room plug"
  • Report on your LAN: "What devices are on my network?", "What's my storage usage?"
  • Write, explain, and debug code and scripts
  • Help you reason through technical problems
  • Generate PowerShell, Python, Bash, or CMD scripts on demand

Chat Controls

  • Brain selector — Choose the AI source. "Auto" uses the bundled AI if available, then falls back to LM Studio.
  • Teaching Mode — Toggle in the chat toolbar. When on, the AI explains step-by-step. When off, it gives concise answers.
  • History — Opens the conversation drawer. Lists all past conversations. Click any to resume it. Delete with the trash icon.
  • Script Request — Checkbox in Advanced Controls. Tells the AI to return valid, runnable script code.
  • Temperature / Max Tokens — Advanced sliders. Temperature controls creativity (0 = precise, 1 = creative). Max tokens limits response length.

AI Source Badge

Below the chat input, the badge shows which AI source is active:

Bundled AI  local model — fully offline    AI Mesh  routed to a LAN peer    Offline  no AI available

Click the badge to open the AI Source modal and change your routing preference. Three options are available:

  • Smart (Recommended) — TLI decides automatically. Uses your local model when it's healthy and your machine has enough resources. Routes to a mesh peer if CPU is above 85% or RAM is above 90%.
  • Local Only — Always use the bundled model on this machine. If the model isn't running, chat is unavailable.
  • Mesh Preferred — Always route to the best available mesh peer. Falls back to local if no peer is available.

TLI switches automatically. If you download a local model and your AI Source was set to Mesh Preferred, TLI switches it to Smart when the model activates — so you're not accidentally routing away from your own hardware.

No AI Installed

If no AI model has been downloaded, a banner appears above the chat input prompting you to download Qwen2.5. Click Download Qwen2.5 to open the AI setup and start the download. The banner dismisses automatically once the model is ready.

Don't want to download AI on this machine? If another computer on your LAN is running TLI with a model installed, you can use that machine's AI instead. Go to the Mesh panel, find the other node, and select it as your AI source via the node switcher in the header. Your chat requests route to that machine — no local model needed.

Quick Start Prompts

The sidebar in the AI Chat panel shows example prompts for common tasks. Click any chip to send it immediately.

Vault Secrets in Chat

If the vault is unlocked, enable Include Vault Secrets in Advanced Controls to inject specific secrets into the AI context. The AI will only reveal them when you explicitly ask. Useful for tasks like "Write a script that connects to my database using my saved credentials."

Conversation Persistence

Every conversation is automatically saved and titled from your first message. When you reload TLI, the last conversation is restored — messages appear with a "messages from last session" divider so you can pick up exactly where you left off. Start fresh with the New Chat button. All history is scoped to your session — other users on the LAN cannot access your conversations.

If the chat returns "No available AI provider": the bundled AI may still be loading (first-run can take 30–60 seconds), or no model is downloaded. Check Settings → AI Model for status.

Vault

An encrypted storage system for sensitive data. Everything in the Vault is protected with AES-256-GCM encryption. Your master password never leaves your machine — only a derived key hash is stored.

Initial Setup

  1. Click Set Up Vault and choose a strong master password. Use at least 12 characters with mixed case, numbers, and symbols.
  2. TLI derives an encryption key using PBKDF2-SHA256 (260,000 iterations, 32-byte random salt). This takes a moment — it's intentionally slow to resist brute force attacks.
  3. Your vault is now initialized. Enter your master password to unlock it.

Session Timeout

The vault auto-locks after 30 minutes of inactivity. Re-enter your master password to unlock. This is a security feature — it cannot be disabled.

Files

Upload any file via drag-and-drop or the Upload button. Files are encrypted at rest on disk. Download decrypts to your browser on the fly. Delete is permanent and unrecoverable.

Secrets

Key-value pairs for passwords, API keys, tokens, and credentials. Add via + Add Secret. Each secret has a name and a value. Secrets can be injected into AI Chat context. The Vault Browser Extension can autofill login secrets directly into websites.

Notes

Encrypted freeform notes. Useful for sensitive documentation, recovery codes, or anything you don't want stored in plaintext. Supports markdown.

Logins

Dedicated login entries with a URL, username, and password field. These are used by the Vault Browser Extension for autofill on websites. Add via + Add Login.

Backup & Restore

  • Export Backup — Downloads an encrypted archive of all vault contents. Store this somewhere safe (external drive, separate machine). TLI cannot recover data without this backup if the machine fails.
  • Reset Vault — Permanently destroys all vault data. Requires your current password + typing RESET VAULT. This is irreversible.

If you forget your master password, your vault data cannot be recovered. The password is never stored. Only a derived key hash exists. There is no backdoor, no reset link, and no way to bypass this. Keep your password somewhere safe.

Home Automation

Control Shelly smart plugs and devices on your LAN. TLI communicates with Shelly devices directly — no Shelly cloud account required.

Adding Devices

  1. Go to Settings → Shelly Devices.
  2. Enter the device's local IP address (find it in your router's device list or the Shelly app).
  3. Assign a friendly name (e.g. "Living Room Lamp", "PC Power Strip").
  4. The device appears in the Home Automation panel immediately.

Manual Control

Each device card shows current relay state (on/off) and live power consumption in watts. Toggle the relay with the switch. The AI can also control devices via chat — just say "Turn off the office plug" or "What is the living room lamp drawing right now?"

Scenes

A scene is a named group of device actions. For example, "Movie Mode" could turn off two lights and turn on a power strip. Create scenes in the Scenes sub-panel and trigger them from the panel or via AI: "Activate Movie Mode."

Automations

Set time-based or condition-based rules (e.g. "Turn off all devices at midnight", "Turn on desk lamp at 8 AM on weekdays"). Automations run on the TLI backend — the browser does not need to be open.

File Storage

Scan directories, visualize disk usage, and organize files with rules.

File Organizer

Click any quick-folder tile — Downloads, Desktop, Documents, Pictures, Videos, Home — to scan it instantly. TLI resolves the real path for your operating system automatically; you never need to type your username or know the full path.

For a custom folder, type any path into the input field and click Scan folder. Results show a breakdown by extension, total size, and a sortable file list.

Use the AI Assistant sidebar to describe what you want done in plain language — e.g. "Move all images to a Photos folder, archive anything older than 2023". TLI generates an organization plan, which you preview before anything moves. Click Run organize to execute, or Undo last to reverse it.

Visualizer

The Visualizer panel shows an interactive treemap of disk usage. Each rectangle represents a file or folder — size is proportional to disk usage. Click to drill down, hover for exact sizes.

Your connected drives are detected automatically and shown as tiles at the top — click any drive to scan it with one click. Quick-folder chips (Downloads, Desktop, Documents, etc.) also appear for instant access to common locations. Connected cloud drives (OneDrive, iCloud, Dropbox, Google Drive) appear as suggestions in the path input if installed.

After scanning, the Safe Cleanup strip identifies cleanup opportunities — temp files, caches, large archives — and lets you act on them with confirmation.

Use the Largest files, Largest folders, and File types tabs to find what's eating your disk. Filter by category, extension, or minimum file size.

Devices

Inventory of connected USB drives, printers, and LAN-connected devices.

USB Storage

Lists all connected USB drives with capacity, free space, and mount point. Click a drive to open it directly in the File Storage scanner.

Printers

Discovers printers automatically — via WMI on Windows, and CUPS on macOS and Linux. Shows name, IP (where available), and status. Send a test page to verify connectivity. On macOS and Linux, click Add Printer to open your OS printer settings directly.

LAN Scan

Scans your local subnet for active devices via ARP. Shows IP addresses, hostnames, MAC addresses, and detected services. Results are cached until the next manual rescan. TLI nodes detected on the LAN are labeled with their node name.

Game Optimizer

Auto-detects running games and generates hardware-aware performance recommendations via the AI.

How It Works

  1. Open the Game Optimizer panel — it starts polling for a running game immediately (foreground process scan every 2.5 seconds).
  2. When a game is detected, TLI shows the title, PID, detected store (Steam, Epic, or direct), and live CPU/RAM metrics.
  3. Select a preset: Max FPS, Balanced, or Quality.
  4. The AI generates tailored settings recommendations based on your hardware and the specific game.

Manual Mode

If your game isn't auto-detected (common with some launchers), click Add Game Manually and paste the full path to the game's .exe. It's added to an allowlist for future scans.

Mesh Network

TLI instances on the same LAN discover each other automatically and can share resources, monitor each other's health, and route AI requests.

How Discovery Works

When TLI starts, it broadcasts a UDP beacon on your LAN every 30 seconds. Any other TLI instance on the same network receives this beacon and adds the sender to its mesh directory automatically. No manual IP entry required — nodes find each other on their own.

Roles

  • Standalone — Default. Not connected to any mesh network. Operates independently.
  • Host — Primary node. Accepts member connections, proxies AI requests from members, and maintains the mesh directory.
  • Member — Connected to a host. Optionally routes AI chat requests to the host. Reports its presence and health to the host.

Manually Joining a Mesh

  1. On the host node: open the Mesh panel and click Become Host.
  2. On the member node: enter the host's IP:port (e.g. 192.168.1.10:8000) and click Join Mesh.
  3. The member appears in the host's Mesh Directory once the first heartbeat is received (within ~30 seconds).

Node Status

Each node in the directory shows a presence badge based on heartbeat age:

Online  last seen <20 seconds    Idle  last seen <2 minutes    Offline  last seen >10 minutes

Remote Diagnostics

Click any node in the Mesh Directory to: Ping it, view live CPU/RAM/disk diagnostics, see Recent Logs, and trigger Maintenance (temp cleanup, refresh).

Node Switcher

The node pills in the header let you switch the AI brain to a different mesh node. If another node has more compute power, you can route your chat requests there without changing any settings.

TLI Chat

Real-time text messaging between TLI nodes on your LAN. Messages go directly to connected nodes — they are not AI-generated.

  • Select a target node from the dropdown (only online mesh nodes appear).
  • Type a message and press Send.
  • Messages appear in the thread with sender name, timestamp, and node origin.
  • Requires at least two TLI instances active on the same LAN.

Tools & Scripts

Generate, save, and run scripts using the AI. Supports PowerShell, Python, Bash, and CMD.

Script Generator

  1. Describe what you need in plain language. Example: "PowerShell script to find files over 1 GB in C:\Users and list them by size."
  2. Select the target shell: PowerShell, Bash, Python, or CMD.
  3. Click Generate — the AI writes the script and it appears in the code editor.
  4. Save stores it to your tools library. Copy puts it on the clipboard.

Saved Tools

Previously generated scripts are listed in the My Tools tab. Run them directly (executes on the TLI backend server), edit, copy, or delete.

Safety Scanner

Before any script is shown, TLI scans it against 15 danger patterns (disk formatting, registry deletion, user deletion, etc.). If a match is found, a warning banner appears. You can still run the script, but you are informed of the risk. Always review scripts before running.

Scripts run on the TLI server process, on the machine where TLI is installed. There is no sandbox. A destructive script will execute destructively. Review every script before clicking Run.

Settings

Set the Node Name and Device Nickname used in the mesh directory, the dashboard narrator, and the AI's system context. The Node ID is auto-generated on first run and cannot be changed.

Access PIN

  • Changing the PIN requires your current PIN.
  • Removing the PIN revokes all active sessions immediately.
  • If you're locked out, use Forgot PIN? on the lock screen to initiate a reset via a server-side verification step.

Shows the status of the bundled AI model — whether it's downloaded, which preset is active, and the current runtime health. From here you can:

  • Switch between Lite, Standard, and Power presets.
  • Download a model if none is installed.
  • See download progress (file size, percent complete).
  • Restart the AI runtime if it becomes unresponsive.

LM Studio URL

If you run LM Studio separately, set its server URL here (default: http://localhost:1234). Use Test Connection to verify. TLI will prefer the bundled AI but can fall back to LM Studio.

Shelly Devices

Add, edit, or remove Shelly smart home devices by IP address and friendly name. Changes take effect immediately in the Home Automation panel.

Theme

Switch between available UI themes. The default is Emerald Light.

AI Providers

TLI supports two local AI providers. On each chat request, it tries them in order:

1. Bundled AI — Qwen2.5

A local LLM that runs entirely on your machine via llama.cpp. No internet required after download. Choose from three presets based on your available RAM:

PresetFile SizeRecommended RAM
Lite (1.5B)~1 GB4 GB+
Standard (3B)~2 GB8 GB+
Power (7B)~4.5 GB16 GB+

The bundled AI knows the current date and time, your node name, your LAN devices, and your mesh state — it is context-aware out of the box.

2. LM Studio

Connect any model loaded in LM Studio. Recommended for heavy code generation and complex reasoning where the 7B Qwen model isn't sufficient. TLI auto-routes to LM Studio if the bundled AI is unavailable or if you select it manually.

3. Mesh AI (another TLI node)

If you don't want to download an AI model on the current machine — due to limited storage, low RAM, or it being a lightweight device — you can route all AI requests to another TLI node on your LAN that has a model installed.

This is ideal for thin clients, older laptops, or any machine where you want to use TLI but not run the AI locally.

  1. On the machine that has the AI model, make sure TLI is running. That node must be visible in the Mesh panel.
  2. On the machine without a model, open the Mesh panel and confirm the other node appears as Online.
  3. Click the node's pill in the header node switcher to select it as your AI source. All chat requests now route to that machine.

The machine doing the thinking is the one with the model. The machine you're sitting at just sends the message and receives the reply — no local compute required beyond running the TLI backend itself.

How Routing Works

TLI's AI chat has three layers that execute in order on every message:

LayerWhat It DoesExamples
Intent EngineDetects control commands. Executes them directly without involving the AI model at all."Turn off the desk lamp", "Run my backup script"
Tool Fast-PathDetects data queries and answers them with real backend data. Authoritative and instant."What's today's date?", "What's my storage?", "Who's on my network?"
LLMEverything that doesn't match the above goes to the local AI model with full context injected."Why is the sky blue?", "Write me a Python script to…"

Vault Browser Extension

The TLI Vault Extension is a Chrome/Edge browser extension that brings your encrypted vault's login credentials directly into any website — inline icons, keyboard shortcut, smart dropdown, and a save-on-submit prompt. No data leaves your LAN.

Setup

  1. In TLI, go to the Vault panel and open the Extension tab.
  2. Click Generate API Key. Copy the key shown — you won't see it again.
  3. Load the extension in Chrome/Edge: go to chrome://extensions, enable Developer mode, click Load unpacked, and select the tli-vault-extension/ folder from the TLI package.
  4. Click the extension icon → Options. Enter your TLI URL (e.g. http://192.168.1.10:8000) and paste the API key.
  5. Click Test Connection. A green confirmation means the extension can reach your vault.

Inline Icon Autofill

On any login page, a small emerald key icon appears inside every username and password field. Click the icon (or press Ctrl+Shift+L) to trigger autofill:

  • One match — fills immediately, no click required.
  • Multiple matches — a dropdown appears below the field. Use ↑ / ↓ to navigate, Enter to fill, Esc to close.
  • No matches — the extension popup opens so you can search all logins.

The fill is React-compatible — works on Single Page Apps that intercept native input events.

Save on Submit

When you submit a login form with a username that isn't already in your vault, a save banner appears at the bottom of the page. Click Save to Vault to store the credentials. The banner dismisses automatically after 12 seconds if ignored.

Extension Popup

Click the TLI extension icon in the toolbar to open the popup. Features:

FeatureDescription

Adding Login Entries

Logins are saved two ways: via the save-on-submit banner (automatic), or manually in the Vault panel → Logins tab → + Add Login. Enter the site URL, username, and password. The domain is extracted from the URL and used for domain matching.

Requirements

  • Vault must be unlocked in TLI before the extension can fetch or save credentials.
  • The TLI backend must be reachable from the browser (same LAN, correct URL in Options).
  • Chrome or Edge (Manifest V3). Firefox support is not included in the current build.

The extension uses an API key (X-TLI-API-Key header) rather than a session cookie. This lets it work independently of your browser session. Keep your API key private — it grants read/write access to your vault logins. Revoke it any time in Vault → Extension → Revoke Key.

LAN Discovery

TLI automatically finds other TLI instances on your network using a lightweight UDP beacon system. No manual IP entry, no configuration — nodes discover each other as long as they're on the same subnet.

How It Works

  • Every TLI instance broadcasts a UDP packet on port 47474 every 30 seconds.
  • The packet contains the node's ID, name, IP address, and TLI port.
  • Any other TLI instance on the LAN receives this packet and immediately adds the sender to its mesh directory.
  • Each node filters out its own broadcasts using its unique node ID.

Firewall Note

At startup, TLI attempts to add Windows Firewall rules for TCP port 8000 (web UI) and UDP port 47474 (discovery). You may see a UAC prompt or firewall notification — allow both to enable LAN access and auto-discovery.

LAN discovery only works between devices on the same subnet (e.g. all on 192.168.1.x). It will not work across different networks or through a VPN unless the VPN bridges layer 2 traffic.

Security & PIN

TLI is designed for trusted home LAN environments. It is not intended to be exposed to the public internet.

Key Security Properties

  • All data stays on your machine and LAN. No telemetry, no cloud sync, no outbound connections except to AI models you configure.
  • Vault encryption: AES-256-GCM with PBKDF2-SHA256 key derivation (260,000 iterations, 32-byte random salt per vault).
  • Sessions are cookie-based (httponly, samesite=strict). Valid for 24 hours, revoked on PIN change/removal.
  • The PIN hash is stored, never the PIN itself.
  • All conversation and memory data is scoped per session user.
  • HTTPS is supported via a self-signed TLS certificate (auto-generated on first run unless disabled).
  • All API responses include security headers: X-Content-Type-Options, X-Frame-Options: DENY, Content-Security-Policy, Permissions-Policy.

Recommended Practices

  • Set an access PIN if anyone else is on your LAN or WiFi.
  • Use a strong vault master password and export a backup.
  • Do not port-forward TLI to the internet (port 8000 should not be accessible outside your home network).
  • Revoke the Vault Extension API key (Settings → Vault → Extension) if you suspect it was exposed.

Troubleshooting

TLI won't open after install

  • The backend may still be starting. Wait 10 seconds and refresh.
  • Check if tli_backend.exe is running in Task Manager.
  • If it crashed, navigate to %AppData%\Local\TheLANIntelligence\ and run start_tli.bat manually to see error output.

Can't access TLI from another device on the LAN

  • Confirm TLI is running on the host machine (open localhost:8000 on the host first).
  • Check that Windows Firewall isn't blocking port 8000. Allow it in: Control Panel → Windows Defender Firewall → Allow an app.
  • Make sure both devices are on the same network (same router/subnet). WiFi and wired devices on the same router are usually on the same subnet.
  • Use the machine's actual IP (ipconfig in terminal), not localhost, from the other device.

AI chat returns "No available AI provider"

  • The bundled AI may still be loading — first start can take 30–60 seconds. Wait and try again.
  • If no model is downloaded, the "No AI" banner appears in chat. Click Download Qwen2.5.
  • Check Settings → AI Model for runtime status and any error messages.
  • If using LM Studio, verify it's running and the URL in Settings is correct.

AI gives wrong date or seems unaware of the current time

The bundled AI is context-aware — it receives the current date, time, and node info with every message. If it still gives wrong information, restart the backend. This resolves any stale runtime state.

Lock screen won't dismiss / PIN not working

  • Make sure Caps Lock is off — the PIN is case-sensitive.
  • Use Forgot PIN? on the lock screen to initiate a reset.
  • Hard-refresh the browser first: Ctrl+Shift+R. A cached version of the app can sometimes get stuck.

Vault says "Vault locked" right after unlocking

The vault auto-locks after 30 minutes of inactivity. This is by design. Re-enter your master password. If it locks immediately after unlock, your session cookie may have expired — hard-refresh and try again.

Mesh node not appearing in directory

  • Ensure both nodes are on the same LAN subnet.
  • UDP port 47474 must not be blocked by either machine's firewall (auto-discovery uses this port).
  • Wait up to 30 seconds after the second node starts — that's the beacon interval.
  • You can also join manually: enter the other node's IP:8000 in the Mesh panel.

Duplicate node entries in Mesh panel

This can happen if TLI was reinstalled on the same machine, generating a new node ID. TLI cleans these up automatically on startup by removing entries with the same display name but a different node ID. If it persists, restart TLI on the host node.

Vault Extension not autofilling

  • Confirm your API key is correct in the extension's Options page and test the connection.
  • Make sure the login entry in TLI's Vault has a URL that matches the site's domain.
  • The extension must be able to reach your TLI instance — confirm the URL in Options is accessible from the browser (open it in a tab to test).
  • If the lock icon doesn't appear on the password field, try clicking Autofill Current Page from the extension popup instead.

Games panel shows "No game detected"

The game scanner reads the foreground window process every 2.5 seconds. The game must be running and in the foreground (not minimized). For launchers that spawn indirect processes, use Add Game Manually with the full .exe path.

Scripts panel warning banner appears unexpectedly

TLI's danger scanner flags 15 patterns including disk formatting, registry deletion, and user account commands. If your legitimate script triggers a false positive, review it carefully before running — the warning is informational, not a block.
