Bluetooth setup

TLI connects through the computer running TLI. Built-in Bluetooth is enough. If that computer lacks Bluetooth, it needs a compatible USB Bluetooth adapter.

This first version supports Windows 11 (build 22000 or newer) and offers an experimental Govee H6125 on/off profile. Other Bluetooth products and light features are not supported by this profile.

TLI is designed for different brands. Setup lists available model integrations; Bluetooth discovery alone does not make a device compatible. The H6125 is the first direct Bluetooth integration, not a requirement for every TLI household.

Prepare the TLI computer

Bluetooth support is an optional installation component. Stop TLI before installing it into the Python environment that runs your host. In the documented source setup, run this from the TLI folder:

.\backend\.venv\Scripts\python.exe -m pip install -r backend/requirements-bluetooth.txt

An installed package may use a different prepared Python environment. Use that environment, then start TLI normally. Nothing on this page installs software, enables Bluetooth, pairs devices or sends a command.

Add your light

  1. Unlock TLI and expand Experimental · Bluetooth lights in Smart home, below the optional Home Assistant connection.
  2. Choose Scan Bluetooth devices. Select your light and its matching integration. Confirm that its printed brand/model matches; currently the list contains Govee H6125.
  3. Give it a unique name and add it. TLI checks its Bluetooth interface without switching the light.
  4. Choose Check state, On or Off deliberately. You can also use its configured name in Ask TLI.
  5. Forget device removes its saved TLI entry after confirmation. It does not switch the light or unpair Windows.

If your light is a different brand

A nearby light may appear even when TLI has no matching Bluetooth integration. Do not select another model to force a connection. More integrations require their own device commands and testing. For lights already configured in Home Assistant, TLI has a separate Optional Home Assistant connection for reviewed state reads and On/Off actions. Its setup and permissions remain separate.

Read the result

Sent means a Bluetooth write completed. A separate reported state is needed to verify on/off. Missing or invalid readings remain unknown. Check the light before repeating an uncertain command; TLI never retries it automatically.

The H6125 profile still needs testing on your actual light. A nearby name and a software-availability message do not prove compatibility or a working Bluetooth radio. Close other apps holding the light if connection fails.

For installation requirements, see the Bleak package documentation. The distributed docs/TLI_BLUETOOTH.md guide records the protocol and acceptance limits.
